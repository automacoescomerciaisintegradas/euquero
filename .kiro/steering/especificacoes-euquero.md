# Especificações do EuQuero

## Descrição do Projeto

EuQuero é uma aplicação web completa desenvolvida com tecnologias modernas, apresentando um frontend React e backend Hono implantado no Cloudflare Workers.

## Idioma da Aplicação

- **Todo o conteúdo deve estar em português brasileiro**
- Interface do usuário completamente em português
- Mensagens de erro e validação em português
- Documentação e comentários em português

## Funcionalidades de Autenticação

### Sistema de Login

1. **OAuth (Google/GitHub)**
   - Integração com Google OAuth
   - Integração com GitHub OAuth
   - Botões de login social na interface

2. **Formulário de Login por Email**

   ```
   Email: [campo de entrada]
   Senha: [campo de entrada]
   [Botão: Entrar]
   ```

3. **Cadastro de Usuário**

   ```
   👤 Usuário:
   Email: [campo de entrada]
   Senha: [campo de entrada]
   Telefone: [campo de entrada]
   [Botão: Cadastrar]
   ```

4. **Confirmação por Email**
   - Envio de email de confirmação após cadastro
   - Verificação via link no email
   - Mensagem: "Confirmar via mensagem no email"
